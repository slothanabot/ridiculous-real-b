A one-sentence startup pitch for make.fun's "Ridiculous at First Glance, Real by the Second" bounty: rental goats that mow your lawn for $30 a visit — it sounds like a farm joke, but suburbs pay because the herd weeds, fertilizes, and never needs gas.

## Run it

```sh
python3 main.py
```

The program writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
